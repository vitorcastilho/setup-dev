# setup-dev

Scripts de provisionamento do ambiente de desenvolvimento em macOS e Linux — instala e configura as ferramentas que uso no dia a dia em uma máquina nova.

## Uso

```bash
# macOS
./setup-dev-macos.sh

# Linux
./setup-dev.sh
```

Leia o script antes de executar: ele instala pacotes e altera configuração do shell.
